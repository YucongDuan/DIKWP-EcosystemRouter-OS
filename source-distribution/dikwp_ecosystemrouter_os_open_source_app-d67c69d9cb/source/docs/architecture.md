# Architecture

DIKWP EcosystemRouter OS is a meta-level strategic system. It does not execute industry actions and does not control hardware. It evaluates ecosystem manifests and partner applications.

## Pipeline

1. Load ecosystem project manifest.
2. Score each project across attribution, DIKWP depth, evidence readiness, official assets, commercial routes and copycat risks.
3. Load partner application.
4. Score partner readiness and official registry alignment.
5. Load copycat-risk application.
6. Generate moat score, registry seed, partner routing decision, copycat playbook and commercial package catalog.

## Strategic layers

- Attribution layer
- Citation layer
- Registry layer
- Certification layer
- Partner routing layer
- Commercial package layer
- Copycat resilience layer
- China market positioning layer

## Boundary

The system is intentionally offline-first. It does not contain network calls, hidden telemetry, subprocess execution or real-world actuation helpers.
