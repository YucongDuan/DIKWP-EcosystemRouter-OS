# Source Synthesis

This system is grounded in the DIKWP idea that information is not enough without purpose and reliability. Energy, information and intention are treated as strategic resources. A public open-source project can diffuse information, but benefit capture requires purpose, evidence, attribution, governance and feedback.

Core source ideas:

- Energy cost and intelligent work require accounting.
- Information abundance can dilute trust unless structured.
- Intention is goal, value, constraint, time and feedback.
- Mesh discipline requires evidence, residual, reliability, Kill and Recovery.
