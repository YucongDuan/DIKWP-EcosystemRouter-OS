# Open Source Launch Plan

## Phase 1: Canonical meta-repo

Create `dikwp-ecosystemrouter-os` as a pinned GitHub repository. Use it to point to the official DIKWP project registry.

## Phase 2: Registry seed

Publish the first `official_registry_seed.json` containing high-quality DIKWP projects with explicit attribution and citation.

## Phase 3: Trust badge

Release a visible badge scheme:

- TP-L0 not ready
- TP-L1 attribution present
- TP-L2 evidence present
- TP-L3 governance present
- TP-L4 registry-ready
- TP-L5 certified partner / official implementation

## Phase 4: Partner onboarding

Invite consulting firms, research labs, open-source maintainers and industry integrators to submit partner manifests.

## Phase 5: Commercial routing

Offer paid registry review, certification training, project audit and China AICAP readiness service.
