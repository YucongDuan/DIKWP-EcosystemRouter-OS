# IP and Open Source Strategy

## Open-source reality

A true open-source license allows use, modification and redistribution. Therefore, open-source protection should not pretend that copying can be prevented.

## Strategy

Use open source to maximize awareness while preserving official ecosystem value through:

- attribution discipline
- citation files
- registry entries
- partner certification
- trademark / brand review
- signed badges
- official commercial route

## Suggested package structure

- Apache-2.0 for code prototypes where broad adoption matters.
- Clear NOTICE for attribution.
- CITATION.cff for academic and software citation.
- Trademark and certification policy outside the code license.
- Enterprise service agreements for paid deployments.

## Legal boundary

This document is not legal advice. Formal trademark, copyright, patent, partner agreement and enforcement strategy require qualified legal review.
