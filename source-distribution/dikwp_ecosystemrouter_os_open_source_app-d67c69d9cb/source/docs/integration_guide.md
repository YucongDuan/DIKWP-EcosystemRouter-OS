# Integration Guide

## With TrustPassport

TrustPassport scores one project. EcosystemRouter scores the whole portfolio and routes partners.

## With ProofLedger

ProofLedger verifies claims. EcosystemRouter uses proof outputs as registry evidence.

## With AgentTrace

AgentTrace captures runtime events. EcosystemRouter uses trace readiness as enterprise trust evidence.

## With AICAP-Gateway

AICAP-Gateway is an implementation prototype. EcosystemRouter protects the strategic ecosystem around it through certification and partner routing.
