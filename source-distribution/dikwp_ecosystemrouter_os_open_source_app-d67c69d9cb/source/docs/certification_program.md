# Certification Program

## Certification levels

- DIKWP Contributor
- DIKWP Trust Steward
- DIKWP Agent Governance Steward
- DIKWP AICAP Integration Steward
- DIKWP Enterprise Partner

## Certification evidence

- Attribution compliance
- DIKWP semantic mapping
- Evidence ledger discipline
- Governance boundary discipline
- Recovery and audit design
- Real project demonstration

## Renewal

Certificates should expire and require updates to project evidence, attribution, and registry status.
