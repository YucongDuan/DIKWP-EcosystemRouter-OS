# GitHub Release Draft

## DIKWP EcosystemRouter OS v0.1.0

This release introduces a strategic open-source ecosystem control plane for DIKWP projects.

### Highlights

- Project portfolio scoring
- Partner routing decision
- Copycat risk analysis
- Official registry seed generation
- Commercial package catalog
- Training certification catalog
- Static boundary audit

### Why it matters

DIKWP projects are expanding across AI governance, RAG evidence, agent security, memory, semantic energy, active health, education, mobility, law and AICAP hardware governance. EcosystemRouter helps turn this expansion into attribution, certification, partner routing and benefit capture.
